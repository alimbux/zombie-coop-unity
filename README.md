# Zombie Coop (Unity)

Порт кооперативного зомби-шутера с Godot 4 ([alimbux/zombie-coop-fps](https://github.com/alimbux/zombie-coop-fps)) на Unity. Первое лицо, разделённый экран на 1–4 игроков, чёрно-белый мир, красная только кровь. Перенесена версия из `main` вместе с разлётом вбок, бильярдными столкновениями, руками-маятниками и падением по физике (PR #12).

## Запуск

1. Установите Unity 6 LTS (6000.0) через Unity Hub. Подойдёт и Unity 2022.3 LTS: если Hub спросит про другую версию редактора, соглашайтесь.
2. В Unity Hub: **Add → Add project from disk**, выберите папку репозитория.
3. При первом открытии Unity скачает пакеты (Input System, Test Framework) и сама создаст сцену `Assets/Scenes/Game.unity`. Если Unity предложит включить новую систему ввода и перезапуститься, нажмите **Yes**.
4. Нажмите **Play**.

Сцена пустая и нужна только для сборки: игра целиком собирается кодом при запуске (`GameRoot`). Если сцены нет, её можно создать из меню **Zombie Coop → Создать сцену и настроить сборку**.

Сборка: **File → Build Profiles** (в 2022.3 — **Build Settings**), платформа macOS, Windows или Linux, **Build**.

## Режимы, оружие и всё остальное

Всё как в Godot-версии, подробности в её [README](https://github.com/alimbux/zombie-coop-fps#readme).

- **Выбраться из здания.** Этажи собираются из комнат, растут с номером этажа, зомби замечают игроков вблизи, на виду или на звук выстрела, нужно всем живым встать на выход.
- **Волны.** Один зал, волны растут, между волнами патроны, оружие, аптечки.
- Нож, пистолет, автомат, дробовик (10 дробин), конечные патроны, передача патронов напарнику, аптечки, подъём упавшего.
- Четыре персонажа с разными силуэтами, зомби с гнилью, бельмами, кишками, три походки.
- Шесть зон попадания, вскрытый череп с мозгами, отрыв рук и ног, ползание на одной ноге или на руках, раны с пульсирующей кровью, обрубки.
- Отдача от пуль, удар ногой с цепным сбиванием, разлёт вбок, бильярдные столкновения, руки-маятники, падение по физике с отскоком.
- Пять форм кровавых пятен, капли с ран, мазки за ползущими.
- Нуар-фильтр (ч/б, контраст, зерно, виньетка), hit-stop на убийстве, все звуки синтезируются кодом.

## Управление

Игрок 1 играет на клавиатуре и мыши, остальные на геймпадах. Если геймпадов хватает на всех, у игрока 1 тоже геймпад.

| Действие | Клавиатура и мышь | Геймпад |
| --- | --- | --- |
| Ходьба | WASD | Левый стик |
| Обзор | Мышь | Правый стик |
| Выстрел, удар ножом | Левая кнопка мыши | Правый курок |
| Сменить оружие | 1–4, Q, колесо мыши | Y |
| Перезарядка | R | X |
| Удар ногой | F или правая кнопка мыши | RB |
| Отдать патроны напарнику | G | B |
| Поднять напарника | Подойти к упавшему и постоять 3 секунды | То же |
| В меню | Esc | Back |

Клик по окну захватывает мышь. В меню: стрелки или крестовина, Enter или A.

## Как устроено

```
Assets/Scripts/GameRoot.cs        меню, запуск режима, экран на 1–4 части, выход с этажа, перезапуск
Assets/Scripts/GameConfig.cs      режим, номер этажа, снаряжение между этажами
Assets/Scripts/LevelGenerator.cs  процедурный этаж: комнаты, двери, выход, зомби, находки
Assets/Scripts/TestRoom.cs        зал для режима «Волны»
Assets/Scripts/ZombieSpawner.cs   волны
Assets/Scripts/Environment.cs     туман, рассеянный свет, блоки стен, лампы
Assets/Scripts/Weapons.cs         характеристики оружия
Assets/Scripts/Pickup.cs          оружие, патроны и аптечки на уровне
Assets/Scripts/Player.cs          игрок: движение, оружие, перезарядка, удар ногой, падение и подъём
Assets/Scripts/PlayerInput.cs     клавиатура, мышь и геймпады (Input System)
Assets/Scripts/PlayerModel.cs     фигуры четырёх персонажей
Assets/Scripts/PlayerHud.cs       интерфейс части экрана
Assets/Scripts/Zombie.cs          зомби: внешность, походки, зоны попадания, отрыв, ползание, отдача, руки, падение
Assets/Scripts/Gore.cs            кровь, раны, мозги, пятна, отлетающие части, hit-stop
Assets/Scripts/BloodStains.cs     формы пятен (рисуются в текстуры при запуске)
Assets/Scripts/Fx.cs              капли крови и комки мозгов (GPU instancing)
Assets/Scripts/Sfx.cs             звуки, синтезированные кодом
Assets/Scripts/MeshKit.cs         меши (капсулы, сферы, цилиндры, коробки), материалы, шарниры, надписи
Assets/Scripts/Util.cs            перевод осей из Godot, слои, случайные числа
Assets/Resources/ZombieCoop/      шейдеры: Lit, Unlit (кровь), Text, Noir (фильтр)
Assets/Editor/ProjectSetup.cs     создаёт сцену и добавляет её в сборку
Assets/Tests/PlayMode/            проверки
```

Каждая часть экрана — своя камера, которая рисует в текстуру, текстура выводится на экран через нуар-фильтр. Проект на встроенном конвейере рендера (Built-in), без URP.

Позы фигур, шарниры и анимации перенесены из Godot числами как есть. В Godot вперёд — это −Z, в Unity — +Z, поэтому позиции и углы переводятся одной функцией (`G.P` и `G.R` в `Util.cs`).

## Проверка

**Window → General → Test Runner → PlayMode → Run All.** Те же проверки, что `tests/smoke_test.gd` в Godot-версии: меню, генератор этажей (связность, выход, нет зомби в стартовой комнате, редкие аптечки), зоны попадания, ползание, походки, вскрытый череп, пятна крови, оружие и патроны, передача патронов, аптечка, перезарядка, отдача дробовика против автомата, удар ногой с цепным сбиванием.

## Чем отличается от Godot-версии

- Яркость ламп, фонаря и тумана подобрана на глаз под освещение Unity и может отличаться от Godot. Числа в `Environment.cs`, `LevelGenerator.cs`, `TestRoom.cs` и `Player.cs` (фонарь).
- Нет кинематографического тонмаппинга Godot (Filmic) и обводки у надписей «ВЫХОД» и подписей находок.
- Не перенесены скрипт снимков экрана для документации и скрипт сборки релизов (`tools/export_all.sh`), готовых сборок в репозитории нет.
